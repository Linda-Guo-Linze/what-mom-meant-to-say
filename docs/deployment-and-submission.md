# Deployment and submission checklist

## Owner actions

1. Create or sign in to a Devpost account and join Hack for Humanity Summer '26.
2. Create a public GitHub repository named `what-mom-meant-to-say` under the owner's account.
3. Provide the GitHub username, preferred Git commit author name, and the exact GitHub noreply email shown under GitHub Settings → Emails.
4. Authorize a Vercel account through GitHub and allow access to this repository only.
5. Add the Groq values from `.env.local` to Vercel's encrypted Environment Variables page. Never paste the key into GitHub.
6. Upload the final video (maximum four minutes) as an unlisted YouTube video or another Devpost-supported public video URL.
7. Add individual or 2–4 person team members by their Devpost usernames and select only eligible prize categories.
8. Review and submit before September 4, 2026 at 11:45 PM EDT; submit early to avoid timezone or upload issues.

## Materials already prepared locally

- English public README and safety explanation
- Five fictional English cases with fixed Stable Demo results
- Eleven paraphrased, source-checked knowledge cards
- Protected OpenAI-compatible Live AI adapter and rate limits
- PWA manifest, mobile/tablet/desktop UI, local profiles, photos, history, and speech
- Devpost draft: `docs/devpost-draft.md`

## Recommended prize selections

- Best Use of AI/ML
- Responsible AI
- Best Design
- Best Innovation
- The applicable mental-health or well-being core category shown in the final Devpost form

Do not select Render-, concussion-, or eligibility-restricted prizes unless the final implementation or team meets their stated requirements.
